# ⚡ Forge — Personal Performance & Habit Tracker

Forge is a modern, full-stack performance and habit-tracking web application designed to help users build consistency, measure progress, and achieve long-term personal goals.

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19, TypeScript)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Database:** [PostgreSQL](https://www.postgresql.org/) (or SQLite/MySQL depending on configuration)
- **ORM:** [Prisma](https://www.prisma.io/)
- **Authentication:** Custom session-based authentication & OTP verification
- **Deployment:** Vercel / Docker

---

## ✨ Features

- 🎯 **Goal Pacing & Tracking:** Set target metrics, track dynamic progress, and auto-calculate completion percentages.
- 📅 **Habit Consistency Matrix:** Daily check-ins with visual progress feedback and weekly performance matrices.
- 📊 **Insights & Analytics:** Interactive donut charts, completion metrics, and dynamic activity rings.
- 🔐 **Secure Authentication:** Passkey/OTP login, password reset workflows, and session management.
- 🌓 **Theme Synchronization:** Built-in light/dark theme toggle support.
